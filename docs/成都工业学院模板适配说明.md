## 我已从模板中提取到的关键规则

### 1. 封面页
- 标题大字样为“本科毕业论文（设计）”
- 标题区说明文字中明确提到：
  - 外文与数字用 `Times New Roman`
  - 三号
  - 加粗
- 题目：
  - 黑体
  - 小二号
  - 加粗
  - 居中
  - 使用下划线
  - 段前 2 行
  - 段后 1 行
  - 单倍行距
- 封面下方信息项包括：
  - 学生姓名
  - 学号
  - 班级
  - 专业
  - 院系
  - 指导教师

### 2. 中文摘要页
- 样式 `61`：`中文摘要 显示固定值`
  - 黑体
  - 15pt 左右（`w:sz=30`）
  - 1.5 倍行距
- 样式 `62`：`中文摘要 内容`
  - 小四号（`w:sz=24`）
  - 首行缩进 2 字符
  - 1.5 倍行距
- 样式 `63`：`中文关键词 显示固定值`
  - 小四号
  - 首行缩进 2 字符

### 3. 英文摘要页
- 样式 `64`：`英文摘要 显示固定值`

  - 14pt 左右（`w:sz=28`）
  - 1.5 倍行距
- 样式 `65`：`英文摘要 内容`
  - 小四号
  - 英文使用 `Times New Roman`
  - 首行缩进 2 字符
  - 1.5 倍行距
- 样式 `66`：`英文关键词 显示固定值`
  - 小四号

### 4. 目录页
- 样式 `67`：`目录 显示固定值`
- 样式 `68`：`目录 一级标题`

- 样式 `70`：`目录 三级标题`

  - 三级标题以上不出现在目录

### 5. 正文章节标题与正文
- 样式 `73`：`章节 一级标题`
  - 黑体
  - 三号（`w:sz=36`）
  - 1.5 倍行距
- 样式 `74`：`章节 二级标题`
  - 黑体
  - 小三号（`w:sz=30`）
  - 1.5 倍行距
- 样式 `75`：`章节 三级标题`
  - 黑体
  - 四号（`w:sz=28`）
  - 1.5 倍行距
- 样式 `76`：`章节 内容`
  - 小四号（`w:sz=24`）
  - 首行缩进 2 字符
  - 1.5 倍行距
- 模板正文说明中还明确给出：
  - 正文为小四号
  - 外文与数字用 `Times New Roman`
  - 段落两端对齐

- 样式 `87`：`章节 表格标题`

- 样式 `88`：`章节 表格单元`
