# 毕业论文插图生成 Prompt 清单

## 使用说明
本文件用于给外部绘图网站、AI 画图工具、流程图工具或 Mermaid/Draw.io 使用。整体风格统一建议如下：

- 风格：本科毕业论文工程图风格
- 背景：纯白
- 线条：黑色或深灰色
- 强调色：尽量少，用浅蓝或浅灰即可
- 字体：中文黑体或宋体风格，清晰可读
- 禁止：卡通风、插画风、3D 渲染风、海报风、夸张图标、发光特效、彩色渐变
- 目标：像论文里的系统结构图、流程图、时序图、模块图，不像宣传海报
